# Tetrika Softskills

Репозиторий учебных материалов онлайн-школы: уроки, мастер-классы, инструменты и материалы для преподавателей.

## Структура

```
tetrika-softskills/
├── index.html              # хаб со ссылками на все отделения
├── README.md
├── _config.yml
│
├── ai/                      # отделение «ИИ»
│   ├── 1-4/                 # 1-4 классы
│   │   ├── lessons/         # уроки курса
│   │   └── masterclasses/   # мастер-классы
│   └── 5-9/                 # 5-9 классы
│       ├── lessons/
│       └── masterclasses/
│
├── yl/                      # отделение «ЮЛ»
│   ├── 1-2/
│   │   ├── lessons/
│   │   └── masterclasses/
│   └── 3-4/
│       ├── lessons/
│       └── masterclasses/
│
├── teachers/                # материалы для преподавателей (сквозные, для всех отделений)
│   ├── guides/               # методички
│   └── training/              # материалы обучения педагогов
│
├── tools/                    # самостоятельные инструменты, переиспользуемые в разных отделениях
│
└── assets/                    # общие ресурсы школы (лого, звуки-заставки и т.п.)
    ├── media/
    └── sounds/
```

## Как добавлять материалы

### Урок
Файлы урока кладутся в `<отделение>/<класс>/lessons/lesson-XX/`, где `XX` — порядковый номер урока внутри курса.

### Мастер-класс
Каждый МК — отдельная папка-инстанс внутри `<отделение>/<класс>/masterclasses/`, названная по дате и теме:

```
masterclasses/2026-06_3d-runner/
├── mk-wizard.html      # сайт-визард для урока
├── presentation.pptx   # презентация
├── sources/            # исходники (сцены, ассеты для МК)
└── visuals/            # визуальные материалы именно этого МК
```

Такой формат позволяет удалить или архивировать целиком один МК, не затрагивая остальные.

### Материалы для преподавателей
Методички и материалы обучения — в `teachers/guides/` и `teachers/training/`, отдельно от ученического контента.

### Общие ресурсы
В `assets/` кладём только то, что используется в нескольких отделениях/курсах (лого школы, общие звуки-заставки). Всё специфичное для конкретного урока или МК хранится внутри его собственной папки.

## Правила именования

- Папки классов: `1-4`, `5-9`, `1-2`, `3-4`
- Папки МК: `ГГГГ-ММ_короткое-название-темы`
- Папки уроков: `lesson-01`, `lesson-02`, ...
