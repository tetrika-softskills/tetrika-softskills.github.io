ГОТОВО ДЛЯ GITHUB PAGES

1. Распакуйте ZIP.
2. Загрузите в корень репозитория файл index.html и папки games и assets.
3. Не меняйте названия файлов и структуру папок.
4. Включите GitHub Pages для корня выбранной ветки.

Игры загружаются только после выбора вкладки. Все изображения хранятся в папке assets.
